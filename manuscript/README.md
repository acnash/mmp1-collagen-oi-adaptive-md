# Manuscript draft

This directory contains the portable manuscript draft generated from the joint adaptive-unwinding report:

- `MMP1_collagen_OI_adaptive_unwinding_manuscript.md`: editable Markdown source;
- `MMP1_collagen_OI_adaptive_unwinding_manuscript.pdf`: six-page rendered draft;
- `figures/`: manuscript figures referenced by the Markdown file.

The draft uses generation 29 as the last common completed generation across wild type, G978S, G984C and G987R. Adaptive maxima are interpreted as evidence of pathway accessibility, not as equilibrium probabilities or free energies.

After running the complete structural analysis described in [`../docs/STRUCTURAL_ANALYSIS.md`](../docs/STRUCTURAL_ANALYSIS.md), download its compact CSV outputs and use them to revise the structural-mechanism sections of the manuscript.
