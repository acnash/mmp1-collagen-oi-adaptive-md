# MMP-1-free apo-collagen systems

These prepared, approximately 150 mM NaCl systems contain collagen without
MMP-1:

- `collagen_G978S/`
- `collagen_G984C/`
- `collagen_G987R/`

Each directory contains the solvated periodic starting structure, collagen
topology, water and ion definitions, force-field includes and a portable
preparation record. The independent velocity states used for the three replicas
per mutant are retained in the
[nine-job Sol bundle](../../MMP1_apo_Sol_1us_200ps/).

See the [apo programme overview](../../projects/apo-collagen/README.md).
