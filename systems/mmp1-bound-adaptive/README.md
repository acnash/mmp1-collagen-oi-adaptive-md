# MMP-1-bound systems for adaptive sampling

These are the production-ready, approximately 150 mM NaCl systems used by the
MMP-1-bound adaptive programme:

- `wild_type/`
- `collagen_G978S/`
- `collagen_G984C/`
- `collagen_G987R/`

Each directory contains the solvated periodic starting structure, collagen and
MMP-1 topologies, water and ion definitions, and the associated force-field
includes. Generated adaptive trajectories are intentionally excluded from Git.

See the [adaptive programme overview](../../projects/mmp1-bound-adaptive/README.md)
and [detailed workflow](../../docs/ADAPTIVE_WORKFLOW_REFERENCE.md).
